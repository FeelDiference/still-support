RAW. Set up once.

Still Setup registers your Sony camera so Still on iPhone can receive original RAW files over Wi-Fi.

Download Still Setup for Mac

Version 1.0.1 · Apple silicon (M1 or later) · macOS 14 or later. English and Russian; switch languages in the app.

Signed with Developer ID and notarized by Apple. Download this helper only from this page or our linked GitHub release.

First-time setup

  1. Download the ZIP on your Mac, unzip it and open Still Setup.
  2. Connect one compatible Sony camera to your Mac with a USB data cable. Select USB Connection → Mass Storage and USB LUN Setting → Single on the camera.
  3. In Finder, eject the camera's memory card with the eject button, but leave the USB cable connected.
  4. Click Prepare camera. macOS asks for your administrator password to access USB. Enter it only in the macOS dialog; Still does not collect it.
  5. After registration succeeds, disconnect USB. Connect the camera and iPhone to the same non-guest Wi-Fi network.
  6. On Sony select Send to Computer. In Still tap Connect for RAW → Find camera.

Registration replaces the camera's previous Send to Computer receiver with Still. It does not delete photos from the memory card. To use another receiver later, register that receiver again using its setup software. The Mac is not needed for subsequent transfers.

Compatibility

Tested with the original Sony α6400 (ILCE-6400). α6000, α6100, α6300, α6500 and α6600 support is experimental. Intel Macs are not supported by this helper. Still for iPhone requires iOS 26 or later.

JPEG does not need a Mac

On Sony choose Send to Smartphone → Select on Smartphone and scan its QR code in Still. This mode sends JPEG files, even when shooting RAW.

RAW. Настроим один раз.

Still Setup регистрирует камеру Sony, чтобы Still на iPhone мог получать оригинальные RAW по Wi-Fi.

Скачать Still Setup для Mac

Версия 1.0.1 · Apple silicon (M1 и новее) · macOS 14 и новее. Русский и английский; переключатель языка — в окне приложения.

Помощник подписан Developer ID и прошёл нотариальную проверку Apple.

Первая настройка

  1. Скачайте ZIP на Mac, распакуйте и откройте Still Setup.
  2. Подключите одну совместимую Sony кабелем с передачей данных. На камере выберите USB Connection → Mass Storage и USB LUN Setting → Single.
  3. В Finder извлеките карту камеры кнопкой ⏏. Кабель оставьте подключённым.
  4. Нажмите Подготовить камеру. macOS запросит пароль администратора для доступа к USB. Вводите его только в системном окне; Still его не собирает.
  5. После успешной регистрации отключите USB. Подключите камеру и iPhone к одной обычной, не гостевой Wi-Fi-сети.
  6. На Sony выберите Отправить на компьютер. В Still — Подключить для RAW → Найти камеру.

Регистрация заменяет прежнего получателя «Отправить на компьютер» на Still. Снимки на карте памяти сохраняются. Для возврата к другому получателю потребуется повторная регистрация его программой. Для последующих передач Mac не нужен.

Совместимость

Проверено с оригинальной Sony α6400. Поддержка α6000, α6100, α6300, α6500 и α6600 экспериментальная. Intel Mac не поддерживается. Для Still нужен iPhone с iOS 26 и новее.

Для JPEG Mac не нужен: выберите «Отправить на смартфон → Выбрать на смартфоне» и отсканируйте QR-код в Still.
